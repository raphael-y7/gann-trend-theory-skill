# 决策规则速查 — 江恩股市趋势理论（专业解读版）

| 能力 | 一句话规则 |
|---|---|
| 趋势判断（多周期+累进高低位+突破旧位） | 月/周定方向、日仅择时；顶底节节抬高为涨势，破旧位入新区间，二次新高更安全。 |
| 支撑/阻力复盘与止损体系 | 旧底下方3点/旧顶上方1—3点挂G.T.C.止损；绝不取消放宽，浮盈止损上移保本。 |
| 吸筹/派发识别（量价×区间×时间三维） | 量除以股本看换手；低位窄幅小量=吸筹，高位大量反复=派发，天量+利好=行情结束。 |
| 七个行动区域位置判别 | 以正常区域为中枢分七区；上3区无消息低开=饱和退出，下3区停止做空等吸筹。 |
| 强弱判别与选股 | 只做活跃领头股：大盘弱它强＝强，破上年高点者领涨；卖弱买强，空股选深跌低价股。 |
| 十二条交易规则与资金管理 | 先定资本分档与单笔风险上限，再避三大致命错误与15条禁令，连亏五到十次仍能交易。 |
| 金字塔式加码 | 顺势加码逐级减量100→50→30→20→10，每档止损跟进；区间内与近顶近底禁止。 |
| 买卖点位与时机 | 高于底10点买、距顶10点卖不设目标价；启动即上车，两天回调买，拿不准就退。 |
| 消息贴现处理 | 消息落地看价格反应定贴现：利好而跌=已贴现，图表与消息抵触时信图表。 |
| 看盘复盘工作流 | 不盯盘：记高低价与量、绘三层图、收盘后判读；日线打折，量除以流通股本。 |
| 失败模式排障检查表 | 亏损先查三大致命错误（过度交易/不止损/摊薄），再按35条失败模式表定位转卡。 |
| 持仓年度体检 | 每年为全部持仓更新月度峰谷图，破多年支撑或高息预警即悉数退出，不待恐慌。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
